# Proofs_in_Elementary_Linear_Algebra

Proofs in Linear Algebra (PELA) is an independent, asynchronous and open access mini-course on proofs in elementary linear algebra. This mini-course is designed to address the transitory period from a typical introductory and computation-based linear algebra course to a proof-based linear algebra course. We'll focus on proof writing as a skill, both in terms of mathematics and in terms of presentation.

Lecture recordings are available at https://www.youtube.com/playlist?list=PL40ydqvvyXfMwFmNvppWUuE3sgOP1RI5-
